# Cockpit Equipment Checks
- [ ] FUEL PUMP switch - APU BOOST
- [ ] APU CONT switch - ON
- [ ] GENERATORS APU switch - ON
- [ ] MFDs - ON
- [ ] Interior/Exterior lighting - Set as required
- [ ] STBY INST switch - ARM
- [ ] EXT PWR switch - OFF and cable disconnected
- [ ] MASTER WARNING PANEL - <span style="color: #00aa00;">#1 ENG OUT, #2 ENG OUT, LOW ROTOR R.P.M</span> segment lights are illuminated
- [ ] LAMPS TEST button - Press and check
- [ ] SAS1, SAS2, TRIM, FPS switches - ON
- [ ] Load mission data
    - On MFD, JMVF - Press
    - LOAD DTS soft key - Press
- [ ] HUD - Set as desired
- [ ] Set up MFD/FD/FMS/EFB for mission
    - TACMAP/ND - As required
    - EFB - Configure aircraft to mission

## Reading the check results

The data page reads **JMVF** on the bezel and **LOAD DTS** beside the on-screen key in V5.2.4. The status flag records a load request. For missing markers, check the [data transfer page](../pilot-handbook/flight-displays/data-transfer-and-aircraft-status.md). For missing route legs, check the [MSFS flight plan](../pilot-handbook/flight-displays/navigation-display-and-flight-plan.md).

The [lamp test](../pilot-handbook/flight-deck/warning-panel-and-lamp-test.md) exercises the warning panel. The [hydraulic leak test](../pilot-handbook/power-and-fuel/hydraulic-leak-test-indications.md) has its own switch and reset. After the cockpit checks, continue with [Starting Engines](Starting%20Engines.md).
