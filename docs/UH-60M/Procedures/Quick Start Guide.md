## Starting the Aircraft
This is a simplified start-up guide to get you in the air as fast as possible. For detailed procedures, please follow the [Normal Procedures](Before_Start.md)

### Systems Prep
- [ ] Parking Brake - Set
- [ ] EGI 1 and EGI 2 switches - ON
    - RAD ALT - ON
- [ ] BATT NO. 1 and NO. 2 switches - ON
- [ ] STBY INST switch - ARM
- [ ] NO. 1 and NO.2 GENERATOR switches - ON
- [ ] AIR SCE HT/STRT - APU
- [ ] FUEL PUMP switch - APU BOOST
- [ ] APU CONT switch - ON
- [ ] GENERATORS APU switch - ON
- [ ] MFDs - ON
- [ ] SAS1, SAS2, TRIM, FPS switches - ON
- [ ] Load mission data
    - On MFD, `JMVF` - Press
    - `LOAD DTC` LSK - Press

### Starting Engines
- [ ] FUEL BOOST PUMP switches - ON
- [ ] ENG FUEL SYS selector(s) - NORM
- [ ] ENGINE IGNITION switch - ON
- [ ] ENG POWER CONT lever(s) - FLY
- [ ] APU CONT switch - OFF
- [ ] HUD - Set as desired

### Weapons

The H-60 features a rudimentary weapons system for the MH-60M and HH-60W models. Arm the weapons via either the EFB, or the `DISP ARM` switch on the center console. The weapons can then be fired via either the **keybindable trigger** or the **EFB Aircraft Menu**.

Weapon impacts are not simulated at this time.
