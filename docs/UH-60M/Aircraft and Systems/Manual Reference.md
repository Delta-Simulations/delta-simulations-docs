## Using the references

Begin with the cockpit label when looking up an indication. **NR** is rotor speed, **RA** is height above terrain, and **REF** identifies the selected display reference. A screenshot that includes the label and its units helps distinguish several numbers that can look similar on adjacent instruments.

When the real aircraft and V5.2.4 behave differently, check the implementation notes on the individual system page. Examples include the engine inputs used by the [EICAS tapes](../pilot-handbook/flight-displays/engine-and-rotor-indications.md), the status flag on the [DTS load screen](../pilot-handbook/flight-displays/data-transfer-and-aircraft-status.md), and the [COUPLE and HOVER selectors](../pilot-handbook/flight-displays/flight-director-and-mode-selectors.md).
