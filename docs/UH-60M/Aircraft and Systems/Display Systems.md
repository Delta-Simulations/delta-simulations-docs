# Cockpit Displays

For departure, keep a **PFD** in front of the flying seat and **EICAS** on the next screen. When you want the route, select **ND** on the adjacent display. Each screen retains its own page selection. If only one stays dark, start with that display's **PWR** switch.

| What you need to read | Instrument |
| --- | --- |
| Attitude, barometric altitude and selected heading | [Primary flight display](../pilot-handbook/flight-displays/primary-flight-display.md) |
| Command bars, **FD1** and selected reference | [Flight director and mode selectors](../pilot-handbook/flight-displays/flight-director-and-mode-selectors.md) |
| Torque, rotor speed and fuel | [EICAS engine and rotor indications](../pilot-handbook/flight-displays/engine-and-rotor-indications.md) |
| Why a message appears | [EICAS crew alerts](../pilot-handbook/flight-displays/crew-alerts-and-test-indications.md) |
| Flight-plan leg or moving map | [ND and flight plan](../pilot-handbook/flight-displays/navigation-display-and-flight-plan.md) · [Moving map controls](../pilot-handbook/communications-and-navigation/moving-map-and-route-entry.md) |
| Drift over a landing spot | [HUD hover cue](../pilot-handbook/flight-displays/head-up-display-and-hover-cue.md) |
| Second attitude or height reference | [Standby instruments](../pilot-handbook/airframe-and-instruments/standby-flight-instruments.md) · [Barometric and radar altitude](../pilot-handbook/flight-displays/barometric-and-radar-altitude.md) |

For individual bezel selections, including **JMVF** and **IVHMS**, use the [multifunction display page list](Multi%20Function%20Display.md).
