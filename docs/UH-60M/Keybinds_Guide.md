# Keybinds Guide

We highly recommend that you bind as many features to a physical control as possible. 

---
## Weapons and Payloads

| Function | MSFS Key Bindings |
|---------|-------------|
| Gun Trigger (Hold) | `MAC_CREADY_SETTING_INC` |
| Bambi/Helitak Release | `MAC_CREADY_SETTING_DEC` |
| Minigun Up | `MIXTURE4_INCR` |
| Minigun Down | `MIXTURE4_DECR` |
| Minigun In | `MIXTURE3_INCR` |
| Minigun Out | `MIXTURE3_DECR` |

## Lighting
| Function | MSFS Key Bindings |
|---------|-------------|
| Searchlight Out | `INC_COWL_FLAPS4` |
| Searchlight In | `DEC_COWL_FLAPS4` |
| Searchlight Left | `INC_COWL_FLAPS3` |
| Searchlight Right | `DEC_COWL_FLAPS3` |
