# Display Systems

!!! warning "Simulation use only"
    Display availability and behavior depend on the Delta Simulations aircraft version and the installed Microsoft Flight Simulator build.

The cockpit's multifunction displays (MFDs) combine flight, engine, navigation, and mission-system information. The manual describes these display formats:

- Primary Flight Display (PFD)
- Navigation Display (ND)
- Engine Instrument Caution/Advisory System (EICAS)
- Tactical map (TAC)
- Joint Variable Message Format (JVMF)
- Integrated Vehicle Health Management System (IVHMS)
- Forward Looking Infrared (FLIR)

The simulated cockpit may not implement every format or data source. The [existing MFD page](../Aircraft%20Systems/Multi%20Function%20Display.md) lists the pages currently documented for the add-on.

## Flight Management System

The Flight Management System (FMS) provides cockpit controls for selected communications, navigation, display, and mission-data functions. In the simulator, only functions explicitly modeled by the add-on are available; simulator avionics integrations can also affect what appears on the displays.
