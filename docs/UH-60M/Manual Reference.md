# Manual Reference and Scope

!!! warning "Simulation use only"
    This documentation describes the Delta Simulations UH-60M in Microsoft Flight Simulator. It is not approved for real-world flight, maintenance, or mission use.

## Source manual

This guide is organized around the subjects covered in *TM 1-1520-280-10, Operator's Manual for UH-60M and HH-60M*, dated 31 October 2017. The manual's chapter structure includes:

| Documentation area | Manual coverage |
| --- | --- |
| Aircraft systems | Chapter 2 |
| Avionics | Chapter 3 |
| Mission and utility equipment | Chapter 4 |
| Operating limits | Chapter 5 |
| Weight, balance, and loading | Chapter 6 |
| Operating procedures | Chapter 8 |

These pages condense and restate selected topics for the add-on. They do not reproduce the source manual or claim that every real-aircraft system is modeled.

## Add-on behavior takes precedence

The aircraft in the simulator is an entertainment and training simulation product. Its switches, displays, flight model, limits, and procedures can differ from the real aircraft and can change between software releases. Where this documentation does not match the installed add-on, use the current add-on behavior and release notes.
