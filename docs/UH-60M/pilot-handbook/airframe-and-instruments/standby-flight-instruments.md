# Standby Flight Instruments

The **Electronic Standby Instrument System (ESIS)** gives the pilots a compact second view of the aircraft's attitude and motion. The standby system has its own display and backup battery. It can display pitch, roll, airspeed, altitude, vertical speed and heading independently of the selected multifunction display page.

## Read the standby picture

| Indication | How to interpret it |
| --- | --- |
| Attitude | The fixed aircraft reference and moving horizon show pitch and bank. The roll pointer reads against the scale above them. |
| Airspeed, altitude and vertical speed | The standby air data computer uses pressure from the pitot-static system. The **BARO** setting provides the pressure reference for displayed altitude. When comparing the main and standby altitudes in the sim, first check that their pressure settings match. |
| Heading | Read the heading tape at its fixed center index. The standby system has a magnetic sensor to supply this information. |

## Other visual references

Look above the instrument panel on the right center windshield frame for the separate magnetic compass. A panel clock offers clock time (**C**) and elapsed time (**ET**). Two direct-reading indicators in the overhead windows show outside air temperature in degrees Celsius. These references can help identify instruments in cockpit views where only their labels are legible.

## The add-on's standby check

Delta's [Before Start checklist](../../Procedures/Before_Start.md) identifies the battery check indication as **BATT GOOD** and calls out the ESIS tone during the standby instrument check. The [Cockpit Equipment Checks](../../Procedures/Cockpit%20Equipment%20Checks.md) list the **STBY INST** switch again. Use the switch position and **BATT GOOD** indication together when checking standby power on the ramp.
