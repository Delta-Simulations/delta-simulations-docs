# Display Power and Bezel Keys

The keys along the bottom of each multifunction display select the page for that screen. Use the physical key directly under the label. The first three keys from the left are the ones you'll use most on an ordinary flight.

| Bezel key | Page | Typical use |
| --- | --- | --- |
| **PFD** | Primary Flight Display | Fly by attitude, airspeed, heading and altitude. |
| **ND** | Navigation Display | Follow the route and identify the next turn. |
| **EICAS** | Engine Instrument Caution/Advisory System | Read engine and rotor indications, main fuel quantity and crew alerts. |

You can keep the PFD in front of you and bring up EICAS on an adjacent screen during startup. Select ND on that same screen once you want the route back. The first screen stays on PFD.

## Power and brightness

Each display has its own **PWR** switch. The **BK LT** rocker adjusts a shared backlight setting, so the other screens can brighten or dim with it. Panel lighting controls the lettering around the displays separately.

If one screen is dark while the others are readable, check its **PWR** switch. If all the screens are dark after loading at a parking spot, follow the electrical setup in the [Quick Start Guide](../../Procedures/Quick%20Start%20Guide.md). When the instruments first load, a solid color can cover the readouts for a few seconds.

On V5.2.4, a second press of **EICAS** from the engine page selects **IVHMS**. Press **EICAS** again to return to the engine instruments.
