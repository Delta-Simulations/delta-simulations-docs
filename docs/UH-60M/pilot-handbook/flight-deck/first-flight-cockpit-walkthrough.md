# First Flight Cockpit Walkthrough

For a first session with the Delta H-60, pick a familiar airport, daylight and clear weather. A parking spot gives you time to find the panels. A runway start can put the aircraft in a different state, so choose the same starting position if you repeat the flight.

## At the parking spot

1. Open the [Before Start checklist](../../Procedures/Before_Start.md). Find the parking brake, standby instrument switch and two battery switches before changing your cockpit view.
2. Follow [Cockpit Equipment Checks](../../Procedures/Cockpit%20Equipment%20Checks.md). When the displays come on, select a flight display on one screen and **EICAS** on another. That gives you a flight picture and an engine picture without changing pages.
3. Use [Starting Engines](../../Procedures/Starting%20Engines.md) for the add-on's start and runup sequence. Watch the two engine-out indicators separately and note which clears first. Check the rotor indication on EICAS as the rotor accelerates.
4. Set a view that shows the attitude display and enough of the windshield to see the horizon. Before leaving the parking area, confirm that you can reach that view again after using the overhead panel.

## A short local flight

Choose one nearby landmark and return to the same airport. On the outbound leg, compare heading on the flight display with your movement over the ground. If you have wind selected in MSFS, the direction the nose points and the track over the ground can differ.

On return, use the [Landing](../../Procedures/Landing.md) and [Parking and Shutdown](../../Procedures/Parking%20and%20Shutdown.md) pages. If something in the cockpit differed from the guide, note the aircraft version, variant, parking or runway start, panel label and indication. Those details make a repeat flight or a bug report much more useful than “startup didn't work.”
