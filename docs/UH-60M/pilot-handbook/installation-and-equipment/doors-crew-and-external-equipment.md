# Doors, Crew and External Equipment

Use **Aircraft** on the cockpit tablet to set up the helicopter on the ramp. The top-down drawing sits above **DOOR CONFIGURATION**. Use the labeled buttons below the drawing, then switch to an outside view to check the result.

## Cockpit and cabin doors

| Tablet control | What changes |
| --- | --- |
| **DOOR L** | Opens or closes the left cockpit door. |
| **DOOR R** | Opens or closes the right cockpit door. |
| **HIDE DOORS** | Hides or restores both front door models. The individual open and closed positions are controlled separately. |
| **TROOP DOOR** | Moves the rear cabin doors. |
| **GUNNER WIN** | Operates the crew window where the variant has a movable window. The HH-60M medical cabin has a sealed section here. |

If a front door appears to be missing, restore it with **HIDE DOORS** before trying **DOOR L** or **DOOR R**. If the cabin doors move oddly on an older installation, the V5.2.4 release includes a correction to the troop-door animation.

## People in the cabin

**CREW VISIBILITY** has four independent switches: **PILOT**, **CO-PILOT**, **CREW CHIEF**, and **TROOPS**. Start with an outside view of the front seats when checking pilot visibility. The cockpit camera has separate visibility rules for pilot body parts. For a clear look at the cabin figures, open the troop doors and inspect from the side.

These buttons control character models. Set the simulated crew and cargo weights in the aircraft payload controls. A photograph of an empty cabin tells you nothing about the load entered there.

## Fittings and equipment

Under **CONFIGURATION**, **SKIS** adds or removes the ski models at the landing gear. **EIBF** controls the engine inlet filter model. Both changes are easiest to see from outside.

The **EQUIPMENT** panel enables **HOIST** and **PROBE** according to the selected variant. On an equipped model, **HOIST** operates the simulated hoist animation. A dimmed button means the current model has no corresponding fitting. If you want to check the animation on an included aircraft, choose an HH-60M Medevac and use the exterior camera.
