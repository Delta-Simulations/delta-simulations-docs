# Flight Controls

!!! warning "Simulation use only"
    This page summarizes the UH-60M for use with the Delta Simulations add-on. It is not pilot training or a checklist for operating a real aircraft.

## Pilot controls

The cockpit has paired pilot and copilot controls. The primary controls are:

| Control | Simulation input | Primary effect |
| --- | --- | --- |
| Cyclic | Cyclic pitch and roll axes | Tilts the rotor disc to control forward, aft, and lateral movement |
| Collective | Collective axis | Changes rotor blade pitch together |
| Pedals | Yaw axis | Controls directional heading through the tail rotor |

The real aircraft links control inputs to the rotor system through mechanical linkages and hydraulic servos. In the simulation, bind each axis to the matching helicopter control and calibrate its range and response in the simulator.

## Stability and flight director functions

The aircraft's automatic flight-control equipment can provide stability augmentation, trim, stabilator control, and flight-director guidance. The exact functions available depend on the simulated aircraft configuration and the add-on's modeled systems.

For the current start-up sequence, see [Normal Procedures](../Operations.md). Switch labels and modeled behavior can vary between add-on versions.
